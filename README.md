# CA306 — STUDIO 2560: ภารกิจนักสื่อสารผู้เท่าทันสิทธิ

เว็บแอป gamification สำหรับกิจกรรมเดี่ยว ~85 นาที ให้นักศึกษาคณะนิเทศศาสตร์ (สาย ดิจิทัลฟิล์ม / นิเทศศาสตร์การตลาด / กระจายเสียงแพร่ภาพและสตรีมมิ่ง) เรียนรู้เรื่องสิทธิมนุษยชนสากลและสิทธิเสรีภาพตามรัฐธรรมนูญไทย 2560 แบบ step-by-step หน้าจอแบ่งเป็นสองคอลัมน์ตลอดทุกด่าน: คอลัมน์ซ้ายคือ "คลังความรู้" อ้างอิง (ปฏิญญาสากลว่าด้วยสิทธิมนุษยชนครบ 30 ข้อ, รัฐธรรมนูญไทย 2560, และสิทธิเสรีภาพสื่อเฉพาะสาย) เปิดดูได้ตลอดเวลา ส่วนคอลัมน์ขวาคือด่านเกมที่นักศึกษาต้องตอบ/เล่นจริง 4 ด่าน พร้อมสถานการณ์จำลอง/ผสมจากเหตุการณ์จริงในสังคมไทย เป็น static site ล้วน ๆ ไม่ต้องมีเซิร์ฟเวอร์หรือฐานข้อมูล เหมาะสำหรับฝากไว้บน GitHub Pages — ต่อยอดจากธีมเดียวกับ `ca306-case-app` และ `ca306-sorting-app`

## ไฟล์ในโปรเจกต์

- `index.html` — โครงหน้าเว็บทั้งหมด (หน้าเริ่ม/เลือกสาย → เข้าสู่ผังสองคอลัมน์ถาวร: คลังความรู้ทางซ้าย + Stage 0 รากฐานสิทธิมนุษยชน → Stage 1 Rapid Rights Quiz → Stage 2 ภารกิจภาคสนาม → Stage 3 ภารกิจบอส → Stage 4 สรุปผล/ใบประกาศนียบัตร ทางขวา)
- `style.css` — ธีม dark futuristic/neon เดียวกับแอปชุดนี้ (ฟอนต์ Kanit + Orbitron, สี cyan/magenta/purple)
- `app.js` — ข้อมูลเกมทั้งหมด (เนื้อหาคลังความรู้/คำถาม/สถานการณ์/แบดจ์) + ตรรกะควบคุมเกม (state machine, ตัวจับเวลา) + export Excel (SheetJS) + export ใบประกาศนียบัตรเป็น JPG (html2canvas) + ส่งผลคะแนนเข้า Google Sheet อัตโนมัติ + ปุ่มส่งผลคะแนนเข้า Microsoft Form (ทางเลือกแทน Google Sheet ดูหัวข้อด้านล่าง)
- `google-apps-script.gs` — โค้ดฝั่ง Google Apps Script ที่ใช้รับผลคะแนนเข้า Google Sheet ของอาจารย์

## วิธีทดสอบก่อนอัปโหลด

เปิดไฟล์ `index.html` ด้วยเบราว์เซอร์ได้เลย หรือรันเซิร์ฟเวอร์เล็ก ๆ ในโฟลเดอร์นี้:

```bash
python3 -m http.server 8000
```

แล้วเปิด `http://localhost:8000`

## วิธีฝากไว้บน GitHub (GitHub Pages) เพื่อให้ได้ URL

1. สร้างบัญชี/ล็อกอิน GitHub แล้วสร้าง repository ใหม่ (เช่นชื่อ `ca306-studio2560-app`) ตั้งเป็น Public
2. อัปโหลดไฟล์ `index.html`, `style.css`, `app.js`, `README.md` เข้า repository (ไฟล์ `google-apps-script.gs` ไม่ต้องอัปโหลดขึ้น GitHub ก็ได้ เพราะใช้แค่ตอนตั้งค่า Google Apps Script เท่านั้น แต่จะอัปโหลดด้วยก็ไม่เสียหาย)
   - วิธีลาก-วาง: ในหน้า repo กด "Add file" → "Upload files" → ลากไฟล์เข้าไป → Commit
   - หรือใช้ Git จากเครื่อง:
     ```bash
     git init
     git add index.html style.css app.js README.md
     git commit -m "CA306 STUDIO 2560 gamification app"
     git branch -M main
     git remote add origin https://github.com/<username>/ca306-studio2560-app.git
     git push -u origin main
     ```
3. เข้าไปที่ repo → **Settings** → **Pages** (แถบเมนูซ้าย)
4. ที่หัวข้อ **Build and deployment** เลือก Source = **Deploy from a branch**, Branch = **main**, folder = **/ (root)** → กด **Save**
5. รอ 1-2 นาที แล้ว refresh หน้า Settings → Pages จะมี URL ให้ เช่น
   `https://<username>.github.io/ca306-studio2560-app/`
6. นำ URL นี้ไปแจกนักศึกษาได้เลย (แนะนำให้เปิดผ่านโปรเจกเตอร์/บอกในคาบเรียน แล้วให้นักศึกษาเปิดจากมือถือ/โน้ตบุ๊กพร้อมกัน)

## วิธีตั้งค่าให้อาจารย์เห็นผลคะแนนทุกคนอัตโนมัติ (Google Sheet)

โดยดีฟอลต์ ไฟล์ Excel และใบประกาศนียบัตร (JPG) จะถูกดาวน์โหลดลงเครื่องนักศึกษาแต่ละคนเท่านั้น อาจารย์จะไม่เห็นไฟล์อัตโนมัติ ถ้าต้องการให้ผลคะแนนของทุกคนไหลเข้ามารวมกันในที่เดียว ให้ทำตามนี้ (ทำครั้งเดียว ใช้เวลาประมาณ 5 นาที ไม่มีค่าใช้จ่าย):

1. เข้า [Google Sheets](https://sheets.google.com) → สร้างสเปรดชีตเปล่าใหม่ 1 ไฟล์ (เช่นตั้งชื่อ "CA306 STUDIO 2560 ผลคะแนนนักศึกษา")
2. เมนู **Extensions** (ส่วนขยาย) → **Apps Script**
3. จะเห็นหน้าต่างแก้โค้ด ลบโค้ดเดิมทั้งหมดในไฟล์ `Code.gs` ออกให้หมด
4. เปิดไฟล์ `google-apps-script.gs` จากโฟลเดอร์นี้ คัดลอกเนื้อหาทั้งหมด ไปวางแทน
5. กด **Deploy** (มุมขวาบน) → **New deployment**
   - กดไอคอนรูปเฟือง เลือกประเภท **Web app**
   - Execute as: **Me**
   - Who has access: **Anyone**
   - กด **Deploy** → อาจต้องกด **Authorize access** แล้วเลือกบัญชี Google ของอาจารย์ → กด "Advanced" → "Go to (ชื่อโปรเจกต์) (unsafe)" → Allow (ระบบเตือนเพราะเป็นสคริปต์ที่เราเขียนเอง ไม่ใช่ของบุคคลที่สาม ปลอดภัย)
   - จะได้ **Web app URL** หน้าตาประมาณ `https://script.google.com/macros/s/xxxxxxxxxxxx/exec` → คัดลอกไว้
6. เปิดไฟล์ `app.js` หาบรรทัด:
   ```js
   const GOOGLE_SCRIPT_URL = "PASTE_YOUR_GOOGLE_APPS_SCRIPT_WEB_APP_URL_HERE";
   ```
   แล้วแทนที่ด้วย URL ที่คัดลอกมาจากข้อ 5 (ใส่ในเครื่องหมายคำพูดเหมือนเดิม)
7. อัปโหลดไฟล์ `app.js` ที่แก้แล้วขึ้น GitHub ทับไฟล์เดิม (หรือ commit ผ่าน git) — เว็บจะอัปเดตเองใน 1-2 นาที
8. ทดสอบ: เปิดเว็บแอป เล่นให้ครบทั้ง 4 ด่านจนถึงหน้าสรุปผล (Stage 4) แล้วกลับไปดูที่ Google Sheet ควรมีแถวผลคะแนนขึ้นมาให้เห็นทันที (แท็บชื่อ "คำตอบ")

จากนั้นทุกครั้งที่นักศึกษาเล่นจบครบ 4 ด่าน ผลคะแนนจะถูกเพิ่มเข้า Google Sheet แผ่นนี้โดยอัตโนมัติ (เฉพาะนักศึกษาที่ติ๊กยินยอมส่งข้อมูลในหน้าแรกเท่านั้น — ดูหัวข้อ "ความเป็นส่วนตัว" ด้านล่าง) อาจารย์เปิดดูหรือดาวน์โหลดเป็น Excel จาก Sheet ได้ตลอดเวลา (File > Download > Microsoft Excel) โดยนักศึกษายังคงได้ไฟล์ Excel และใบประกาศนียบัตร (JPG) ส่วนตัวดาวน์โหลดไว้ที่เครื่องด้วยเช่นเดิม

## ทางเลือกอื่นแทน Google Sheet: ส่งผลคะแนนผ่าน Microsoft Forms (สำหรับอาจารย์ที่ใช้ระบบ Microsoft 365)

Microsoft Forms ไม่มีช่องทางให้เว็บภายนอกส่งคำตอบเข้าไปแบบเงียบ ๆ อัตโนมัติทั้งหมดเหมือน Google Apps Script ได้ (ไม่มี public API สำหรับ "เขียน" ข้อมูลเข้าฟอร์ม มีแต่ API สำหรับ "อ่าน" คำตอบที่มีอยู่แล้วเท่านั้น) แอปนี้จึงใช้วิธี **ลิงก์กรอกข้อมูลล่วงหน้า (Pre-filled link)** แทน คือระบบจะกรอกคำตอบของนักศึกษาไว้ให้ในฟอร์มอัตโนมัติ แล้วเปิดแท็บใหม่ให้ ส่วนนักศึกษาต้องกดปุ่ม "ส่ง" (Submit) ในหน้าฟอร์มเองอีกครั้งหนึ่งเพื่อยืนยัน (มีขั้นตอนเพิ่มจาก Google Sheet 1 ขั้นตอน แต่ไม่ต้องพึ่งบัญชี Google เลย)

### วิธีตั้งค่า (ทำครั้งเดียว)

1. เข้า [forms.office.com](https://forms.office.com) ล็อกอินด้วยบัญชี Microsoft ของมหาวิทยาลัย แล้วสร้างฟอร์มใหม่ (เช่นตั้งชื่อ "CA306 STUDIO 2560 ผลคะแนนนักศึกษา")
2. เพิ่มคำถามแบบ **Text (คำตอบสั้น)** ทั้งหมด 8 ข้อ ตามลำดับนี้ (ใช้ Text ล้วนแม้เป็นตัวเลข เพื่อไม่ให้ระบบ validate พลาดตอน prefill): รหัสนักศึกษา, ชื่อ, นามสกุล, สาย, RightsPoints, InsightPoints, คะแนนรวม, แบดจ์ที่ได้
3. **สำคัญมาก:** กดปุ่ม "..." (More options) มุมขวาบน → **Settings** → หัวข้อ "Who can fill out this form" → เลือก **"Anyone can respond"** (ถ้าจำกัดเฉพาะคนในองค์กร ลิงก์ prefill จะทำงานไม่ถูกต้อง เพราะระบบจะพยายามดึงคำตอบเก่าของ session มาแทนค่าที่ prefill ไว้)
4. ที่หน้าฟอร์ม กดปุ่ม **"..."** → **"Get pre-filled link"** → เปิดสวิตช์ **"Enable pre-filled answers"**
5. กรอกค่าตัวอย่างลงไปในแต่ละช่องคำถามให้ครบ (ค่าอะไรก็ได้ เช่น `TEST001`, `ทดสอบ` ฯลฯ) แล้วกด **"Get Prefilled Link"** จะได้ URL ยาว ๆ
6. เปิดไฟล์ `app.js` หาค่าคงที่ `MS_FORMS_BASE_URL` และ `MS_FORMS_FIELD_IDS` ใกล้ ๆ กับ `GOOGLE_SCRIPT_URL` แล้วแทนที่ด้วยค่าจาก URL ที่ได้ในข้อ 5:
   - ส่วน `id=xxxxxxxx...` (ก่อน `&` ตัวแรก) → ใส่ใน `MS_FORMS_BASE_URL`
   - พารามิเตอร์ `r...=` แต่ละตัว (เช่น `r0d5d346dca...=TEST001`) → จับคู่ให้ตรงกับคำถามที่กรอกค่านั้นไว้ ใส่ใน `MS_FORMS_FIELD_IDS` ตามช่องที่ตรงกัน (ดูตัวอย่างที่ใส่ไว้แล้วในไฟล์เป็นแนวทาง)
7. อัปโหลดไฟล์ `app.js` ที่แก้แล้วขึ้น GitHub ทับไฟล์เดิม
8. ทดสอบ: เล่นแอปจนถึง Stage 4 (สรุปผล) ควรเห็นปุ่ม "📝 ส่งผลคะแนนเข้า Microsoft Form ของอาจารย์" ปรากฏขึ้น (ปุ่มนี้จะซ่อนอัตโนมัติถ้ายังตั้งค่าไม่ครบ หรือถ้านักศึกษาไม่ได้ติ๊กยินยอมส่งข้อมูลในหน้าแรก) กดแล้วตรวจสอบว่าแท็บใหม่เปิดฟอร์มพร้อมข้อมูลกรอกไว้ถูกต้องครบทุกช่อง แล้วลองกด Submit ดูว่าคำตอบเข้า Microsoft Forms จริง

จะเปิดใช้ทั้ง Google Sheet และ Microsoft Forms พร้อมกันก็ได้ (ตั้งค่าทั้งสองอย่าง) หรือจะใช้อย่างใดอย่างหนึ่งก็ได้ ถ้าไม่ตั้งค่า `MS_FORMS_BASE_URL`/`MS_FORMS_FIELD_IDS` ปุ่มนี้จะไม่แสดงเลย ไม่กระทบการทำงานส่วนอื่นของแอป

## พฤติกรรมของแอป

- **หน้าแรก:** กรอกรหัสนักศึกษา + ชื่อ + นามสกุล, เลือกสายวิชา (ดิจิทัลฟิล์ม / นิเทศศาสตร์การตลาด / กระจายเสียงฯ) และติ๊กยินยอมให้ส่งผลคะแนนเข้า Google Sheet (ไม่บังคับติ๊ก — ถ้าไม่ติ๊ก แอปจะยังใช้งานได้ปกติ เพียงแค่ไม่ส่งข้อมูลออกไปไหน)
- **คลังความรู้ (คอลัมน์ซ้าย ถาวรทุกหน้าตั้งแต่ Stage 0 เป็นต้นไป):** แสดงเนื้อหาหลักการสิทธิมนุษยชนและสิทธิเสรีภาพเป็น 5 หมวดหมู่ (ปุ่มเรียงในคอลัมน์ซ้าย คลิกแล้วเนื้อหาขึ้นด้านล่างแบบเลื่อนอ่านได้): ปฏิญญาสากลว่าด้วยสิทธิมนุษยชน (UDHR) ครบทั้ง 30 ข้อ, รัฐธรรมนูญไทย 2560 (บุคคลทั่วไป), และสิทธิเสรีภาพสื่อเฉพาะสาย 3 หมวด (ดิจิทัลฟิล์ม / การตลาด / กระจายเสียง) คอลัมน์นี้ค้างอยู่ตลอดขณะที่คอลัมน์ขวาเป็นด่านเกมที่นักศึกษาต้องเล่น/ตอบจริง ทำให้เปิดดูเนื้อหาประกอบก่อนตอบคำถามได้ตลอดโดยไม่ต้องออกจากหน้าด่าน — การคลิกดูหมวดหมู่ใดก็ได้ก่อนตอบในแต่ละด่าน (Stage 1 / 2 / 3) ยังได้ InsightPoints เพิ่มด่านละ 12 คะแนน (ให้ครั้งแรกที่คลิกในด่านนั้นเท่านั้น)
- **Stage 0 — รากฐานสิทธิมนุษยชน:** จับคู่หลักการสากลจาก UDHR กับมาตราในรัฐธรรมนูญไทย 2560 ที่ตรงกัน พร้อมโจทย์สถานการณ์สั้น ๆ ประกอบ
- **Stage 1 — Rapid Rights Quiz:** คำถามปรนัย 12 ข้อ จับเวลาข้อละ 45 วินาที
- **Stage 2 — ภารกิจภาคสนาม:** สถานการณ์แบบเลือกทางแยก (branching) 4 สถานการณ์ต่อสาย ปรับตาม track ที่เลือก มีกลไก "Freedom-Responsibility Meter" แสดงจุดสมดุลของแต่ละตัวเลือก
- **Stage 3 — ภารกิจบอส "Colliding Rights":** โจทย์สิทธิที่ปะทะกัน ให้เลื่อนสไลเดอร์แสดงจุดยืนแล้วเขียนเหตุผลประกอบ เป็นด่านสุดท้ายก่อนสรุปผล เหตุผลที่เขียนละเอียดจะได้ทั้ง InsightPoints และ RightsPoints
- **Stage 4 — สรุปผล:** แสดง RightsPoints / InsightPoints / คะแนนรวม, แบดจ์ที่ปลดล็อก, คำถามชวนคิดต่อท้ายคาบ (debrief), ปุ่มดาวน์โหลดใบประกาศนียบัตร (JPG) และไฟล์ผลคะแนนแบบละเอียดทุกด่าน (Excel หลายชีต)
- ความคืบหน้าทั้งหมดถูกบันทึกอัตโนมัติใน `localStorage` ของเบราว์เซอร์ — หากรีเฟรชหน้าโดยไม่ตั้งใจระหว่างเล่น แอปจะพากลับไปยังด่านที่ค้างไว้โดยอัตโนมัติ (ข้อมูลอยู่เฉพาะในเครื่องของนักศึกษาแต่ละคน)
- ปุ่ม "↺ เริ่มใหม่" มุมบนขวา (ปรากฏตั้งแต่ Stage 0 เป็นต้นไป) และปุ่ม "↺ เริ่มกิจกรรมใหม่ทั้งหมด" ในหน้าสรุปผล Stage 4 ใช้ล้างความคืบหน้าใน `localStorage` แล้วรีเฟรชหน้ากลับไปเริ่มใหม่ตั้งแต่หน้าแรก มีกล่องยืนยันก่อนลบเสมอเพื่อกันการกดพลาด — มีประโยชน์เวลาทดสอบเว็บซ้ำหลายรอบหรือให้นักศึกษาคนถัดไปเล่นต่อบนเครื่องเดียวกัน
- ไฟล์ที่ดาวน์โหลดได้: ใบประกาศนียบัตร `<รหัสนักศึกษา>_<ชื่อ><นามสกุล>_ใบประกาศนียบัตร.jpg` และผลคะแนน `<รหัสนักศึกษา>_<ชื่อ><นามสกุล>_STUDIO2560.xlsx` (มี 5 ชีตย่อย: สรุปคะแนน, Stage0 รากฐานสิทธิ, Stage1 Quiz, Stage2 ภารกิจภาคสนาม, Stage3 ภารกิจบอส)

## ความเป็นส่วนตัว

แอปนี้ออกแบบตามหลัก "Walk the talk" — เนื้อหาสอนเรื่องสิทธิความเป็นส่วนตัว จึงต้องเคารพสิทธิของผู้เล่นเองด้วย: การส่งผลคะแนนเข้า Google Sheet จะเกิดขึ้นก็ต่อเมื่อนักศึกษาติ๊กยินยอมในหน้าแรกเท่านั้น (checkbox `#consentCheck`) และไม่มีการเก็บข้อมูลใด ๆ นอกเหนือจากรหัสนักศึกษา ชื่อ-นามสกุล สายวิชา และผลคะแนน

## การปรับแต่ง

- แก้ไข/เพิ่ม-ลดเนื้อหาคลังความรู้ได้ที่ตัวแปร `KNOWLEDGE_BASE` ในไฟล์ `app.js` (แต่ละหมวดมี `intro` และ `sections` เป็นหัวข้อย่อย h/p)
- แก้ไข/เพิ่ม-ลดคำถามและสถานการณ์ได้ที่ตัวแปรในไฟล์ `app.js`: `FOUNDATION_ITEMS` (Stage 0), `QUIZ_QUESTIONS` (Stage 1), `SCENARIOS` (Stage 2, แยกตาม track), `BOSS_SCENARIOS` (Stage 3, แยกตาม track), `BADGES` (เงื่อนไขปลดล็อกแบดจ์), `DEBRIEF_QUESTIONS` (คำถามชวนคิดท้ายคาบ)
- ปรับคะแนนโบนัสจากการคลิกดูคลังความรู้ก่อนตอบ (ค่าเริ่มต้น +12 InsightPoints ต่อด่าน) ได้ในฟังก์ชัน `awardLibraryBonus()` ของไฟล์ `app.js`
- แก้ไขสีธีมได้ที่ตัวแปร CSS variables ด้านบนของไฟล์ `style.css` (`--cyan`, `--magenta`, `--purple`, ฯลฯ)
- ระยะเวลาต่อข้อของ Stage 1 (ค่าเริ่มต้น 45 วินาที) ปรับได้ที่ตัวแปร `timeLeft` ในฟังก์ชัน `renderQuiz()` ของไฟล์ `app.js`
